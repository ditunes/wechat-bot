# 项目简介 / Project Introduction
我们希望做一些工具让组织变得更加透明和阳光。我们讨厌愚蠢和重复的工作，我们讨厌黑暗！

We hope to build tools that make organizations more transparent and sunny. We hate stupid and repeatable work, and we hate the darkness!

# 如何构建 / How to Build

## npm
* 你应该安装 Chrome WebDriver，可以从这里下载 / You should install Chrome WebDriver, you can download it from [here](https://sites.google.com/a/chromium.org/chromedriver/)
* 执行 `npm install` 下载依赖，并全局安装 TypeScript / Execute `npm install` to download node_modules and `npm install typescript -g`
* 然后运行 `npm run start` / Then you can run `npm run start`

## docker
* `docker pull zixia/wechaty`
* 然后执行 `startup.sh` / Then execute `startup.sh`
